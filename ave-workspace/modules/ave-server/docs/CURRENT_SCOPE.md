# 현재 서버 범위

## 서버 책임

서버는 클라이언트가 사용하는 원격 API의 인증, 요청 처리, 결과 반환을 담당합니다. 사용자와 작업 소유권을 검증하고, 분석 작업 이력과 추천 개선에 필요한 데이터를 저장합니다. LLM과 원격 Whisper API의 비밀 값도 서버 `.env`에서만 관리합니다.

## 저장하지 않는 데이터

원본 영상, 렌더링 결과 영상, 클라이언트의 로컬 파일 경로는 서버와 메인 DB에 저장하지 않습니다. 서버가 저장하는 대상은 스크립트 중요도, 채팅 밀도, 댓글 타임스탬프, 히트맵, 음량, 추천·선택·수정 이력 등 분석 데이터입니다.

## 임시 오디오 전사

클라이언트는 STT가 필요할 때만 임시 오디오를 HTTP로 업로드합니다. 서버는 원격 Whisper API가 접근할 수 있는 제한 시간 URL을 제공하고 전사 결과를 반환합니다. 전사가 끝나면 임시 파일을 삭제하며, FTP는 사용하지 않습니다.

## 실행

서버는 Docker와 Caddy를 사용해 실행합니다. 실제 VM 배포 절차는 `../deploy/README.md`, API 계약은 `API.md`를 기준으로 합니다.

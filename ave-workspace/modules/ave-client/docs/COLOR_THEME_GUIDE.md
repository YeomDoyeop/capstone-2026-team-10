# UI 색상 테마 현황 및 변경 요청 기준

## 문서 목적

이 문서는 현재 AVE 웹 UI에 실제로 적용된 색상과 용도를 정리한 기준표다. UI 색상 변경 요청을 받을 때 이 표의 **역할명**을 기준으로 변경 범위와 결과를 합의한다.

테마의 기준 파일은 `ui/src/WorkflowApp.css`이며, 실제 화면은 `ui/src/WorkflowApp.tsx`가 렌더링한다. `static/ui`는 빌드 결과물이므로 직접 수정하지 않는다.

## 현재 테마 선택 방식

| 항목 | 현재 구현 |
| --- | --- |
| 선택값 | `localStorage`의 `ave-theme` |
| 적용 위치 | `<html data-theme="light">` 또는 `<html data-theme="dark">` |
| 전환 제어 | 헤더의 테마 전환 버튼 |
| 색상 정의 | `WorkflowApp.css`의 `:root` 및 `:root[data-theme="dark"]` |

## 테마 변경 요청 방법

색상 변경을 요청할 때 아래 형식으로 알려주면, 영향을 받는 UI를 빠짐없이 수정할 수 있다.

```text
- 변경할 역할: 주요 강조
- 현재 느낌 또는 색상: 밝은 주황색 (#f97316 / 다크 #fb923c)
- 원하는 방향: 더 푸른 계열의 차분한 색상
- 적용 범위: 주요 버튼, 활성 탭, 진행률, 히트맵 막대 모두
- 유지할 요소: 선택 구간의 연한 배경은 현재대로 유지
```

원하는 결과를 색상 코드 대신 표현으로 전달해도 된다. 예를 들면 다음과 같다.

- “배경을 더 따뜻한 회색으로 바꿔 주세요.” → 페이지 배경과 표면의 후보 색상을 제안
- “버튼과 히트맵을 서로 다른 색으로 분리해 주세요.” → 주요 강조와 히트맵 전용 강조 역할을 분리
- “다크 모드에서 글자가 너무 밝습니다.” → 기본 글자와 보조 글자만 조정
- “경고와 오류를 눈에 띄게 표시해 주세요.” → 현재 없는 경고·오류 상태색을 추가하고 해당 상태 UI까지 연결
- “보조 버튼의 파란색을 더 차분하게 바꿔 주세요.” → 보조 강조와 연한 보조 강조 배경만 변경

## 변경 처리 기준

1. 같은 역할의 색상은 라이트와 다크 테마에서 함께 변경한다.
2. “버튼 색상”처럼 화면 요소를 지칭한 요청은 위 화면별 적용표에서 연결된 역할 전체에 적용할지 먼저 확인한다.
3. 일부 화면만 다른 색이 필요한 경우, 기존 역할을 덮어쓰지 않고 해당 목적의 새 역할을 추가한다. 예: 히트맵만 다른 색이 필요하면 `--ave-heatmap`을 추가한다.
4. 색상 변경 후 라이트/다크 양쪽에서 텍스트, 테두리, 선택 상태, 진행률, 히트맵을 확인한다.
5. 변경은 반드시 `ui/src`에 적용하고, 이후 `ui` 디렉터리에서 빌드한다.
6. 호버 효과는 `:disabled`가 아닌 버튼과 다운로드 링크에만 적용한다. 주요 주황색 버튼은 주황색, 보조 버튼과 테마 버튼은 파란색 계열로 하이라이트한다. 비활성화 버튼에는 이동·하이라이트 효과를 적용하지 않는다.
7. 입력창·선택창·텍스트 영역의 포커스 표시는 단일 파란 테두리로 통일한다. 브라우저 기본 포커스 색상이나 이중 외곽선에 의존하지 않는다.
8. Phase 2의 선택 메뉴는 운영체제 기본 드롭다운이 아닌 React 커스텀 메뉴를 사용한다. 마우스를 올린 항목만 `--ave-select-selected` 연한 회색으로 표시하고, 포인터가 벗어나면 즉시 해제한다.

## 현재 미정의 상태색

완료·경고·오류·정보 전용 색상은 아직 공통 테마 변수로 정의되어 있지 않다. 이 상태들을 별도 색상으로 구분하길 원할 때 다음 역할을 추가한다.

| 추가 역할 | 예정 용도 |
| --- | --- |
| 성공 | 완료 상태와 성공 알림 |
| 경고 | 확인이 필요한 안내 |
| 오류 | URL 검증 실패, API 실패 등 |
| 정보 | 중립적 시스템 안내 |
| 포커스 | 키보드 탐색 시 입력·버튼 강조 |

빌드 및 소스 관리 원칙은 [프론트엔드 빌드 원칙](FRONTEND_BUILD_PRINCIPLES.md)을, 화면 크기 기준은 [반응형 디자인 기준](RESPONSIVE_DESIGN.md)을 따른다.

# 반응형 UI 기준

## 화면 구분

AVE 클라이언트 UI는 뷰포트 너비 **1024px**를 데스크톱과 모바일 레이아웃의 단일 전환 기준으로 사용한다.

| 구분 | 뷰포트 너비 | 레이아웃 원칙 |
| --- | --- | --- |
| 데스크톱 | 1025px 이상 | 넓은 화면을 활용해 다열 레이아웃을 사용한다. |
| 모바일 | 1024px 이하 | 콘텐츠와 조작 요소를 한 열 중심으로 재배치한다. |

## 적용 규칙

모바일 구간에서는 다음을 적용한다.

- 헤더와 영상 검토 영역을 세로로 배치한다.
- 메타데이터와 분석 설정 카드를 한 열로 표시한다.
- 하단 진행률 도크를 두 열로 재배치하고 상태 메시지와 동작 버튼은 전체 너비를 사용한다.
- 별도의 세부 모바일 조정은 기존 560px 이하 규칙으로 유지한다.

## 구현 위치

기본 반응형 규칙은 `ui/src/WorkflowApp.css`의 `@media (max-width: 1024px)`에서 관리한다. React UI를 빌드하면 `static/ui/`에 반영된다.

# AVE 프로젝트

## 개요

AVE(Automatic Video Edit)는 영상의 내용을 분석하고 자동 편집을 지원하기 위한 프로젝트이다.

영상 처리, 음성 인식, AI 분석 등의 기능을 조합하여 사용자가 영상 편집 작업을 보다 쉽게 수행할 수 있도록 하는 것을 목표로 한다.

## 간략한 모듈별 기능

* ave-client
  * 사용자 PC에서 실행되는 클라이언트 모듈. 로컬 서버와 웹 기반 사용자 인터페이스를 포함하며, 영상 처리 요청과 결과 확인 등 사용자와 직접 상호작용하는 기능을 담당한다.
* ave-dist
  * ave-client를 실제 사용자에게 배포하기 위한 모듈. 실행 파일 또는 설치 패키지 생성 등 클라이언트 배포와 관련된 작업을 담당한다.
* ave-server
  * 중앙 백엔드 서버 모듈. 클라이언트 요청을 처리하고 LLM, STT 등 외부 또는 내부 서비스를 호출하며, 서비스의 주요 서버 측 로직을 담당한다.
* ave-whisper-api
  * Whisper 기반 STT 전용 백엔드 모듈. faster-whisper와 GPU 실행 환경을 이용해 오디오를 텍스트와 세그먼트 타임스탬프로 변환하는 API를 제공한다.

## 기본 방향

* 기능을 작은 단위로 구현하고 실제 동작을 확인한다.
* 가능한 단순한 구조를 우선한다.
* 모듈 간 결합을 최소화한다.
* 각 모듈은 가능한 한 독립적으로 실행하고 테스트할 수 있도록 한다.
* 새로운 요구사항이 생길 때 필요한 설계와 문서를 추가한다.

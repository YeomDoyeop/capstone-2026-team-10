# AVE 프로젝트

## 개요

AVE(Automatic Video Edit)는 영상의 내용을 분석하고 자동 편집을 지원하기 위한 프로젝트이다.

영상 처리, 음성 인식, AI 분석 등의 기능을 조합하여 사용자가 영상 편집 작업을 보다 쉽게 수행할 수 있도록 하는 것을 목표로 한다.

## 간략한 모듈별 기능

* ave-client
  * 사용자 PC에서 실행되는 클라이언트 모듈. 로컬 서버와 웹 기반 사용자 인터페이스를 포함하며, `yt-dlp`, FFmpeg 등 로컬 도구를 사용한 영상 수집·분석·렌더링과 사용자 작업 제어를 담당한다.
* ave-dist
  * 향후 PyInstaller 기반 Windows 포터블 앱 설정과 배포 산출물을 관리할 모듈. 현재는 패키징을 진행하지 않는다.
* ave-server
  * 중앙 백엔드 서버 모듈. AVE의 API 요청 처리와 결과 반환, 사용자 인증, 외부 서비스 호출, 작업 이력과 분석 데이터 저장을 담당하며, 축적된 데이터를 기반으로 향후 추천·머신러닝 기능을 제공한다. 원격 STT가 필요한 경우 전사용 오디오의 임시 호스팅도 담당한다.
* ave-whisper-api
  * WhisperX 기반 STT 전용 백엔드 모듈. `large-v3` 전사와 언어별 CTC 강제 정렬을 GPU에서 한 번 수행해 오디오를 텍스트와 정렬된 세그먼트·단어 타임스탬프로 변환한다. 기존 faster-whisper 전용 엔진은 모듈 내부 `legacy/`에 보존한다.

## 모듈 간 데이터 경계

원본 영상과 렌더링 결과 영상은 사용자 PC의 `ave-client`에서만 관리한다. `ave-server`는 영상 파일이나 로컬 파일 경로를 수집·저장하지 않는다.

원격 STT를 사용할 때에는 클라이언트가 추출한 전사용 오디오를 `ave-server`에 임시 전송할 수 있다. 서버는 이 오디오를 `ave-whisper-api`가 접근 가능한 HTTPS URL로 제한된 기간 동안 호스팅하고, 전사가 끝난 뒤 삭제한다. 이 임시 오디오는 메인 분석 데이터나 영상 보관 데이터로 취급하지 않는다.

클라이언트는 편집 추천과 선택 결과를 재현·개선하는 데 필요한 분석 데이터만 서버에 전송한다. 대표 데이터는 다음과 같다.

* 스크립트와 구간별 스크립트 중요도
* 구간별 채팅 밀도
* 댓글에서 언급된 타임스탬프와 집계값
* 영상 히트맵 정보
* 구간별 사운드 데시벨 등 음향 분석값
* AI 추천 구간, 사용자의 선택·제외·수정 이력 및 최종 편집 결과에 대한 피드백

서버는 사용자·작업·영상 식별자와 위 분석 데이터를 연결해 저장한다. 서버에 영구 저장하는 데이터는 원본 영상 대신 분석 결과를 직렬화한 데이터로 제한한다. 서버에 저장하는 식별자는 로컬 절대 경로가 아닌 클라이언트가 생성한 작업 ID, 영상 소스 ID 또는 익명화 가능한 참조 ID를 사용한다.

## 기본 처리 흐름

1. 클라이언트가 인증된 사용자 기준으로 로컬 작업을 시작한다.
2. 클라이언트가 URL에서 영상·음성과, 가능한 경우 스크립트·자막·채팅 리플레이·히트맵·챕터·댓글 메타데이터를 수집하고 음량을 분석한다.
3. 기존 스크립트를 쓸 수 없을 때만 클라이언트가 전사용 오디오를 서버에 임시 전송하고, 서버가 `ave-whisper-api` 호출과 전사 결과 반환을 담당한다.
4. 서버는 전체 스크립트의 챕터 분할과 챕터별 섹션·문장 중요도 분석을 LLM에 요청한다. 이 교환에는 문장 인덱스와 텍스트를 담은 JSONL 형식을 사용한다.
5. 현재는 LLM 중요도를 기준으로 추천 구간을 만든다. 향후 채팅, 댓글 타임스탬프, 히트맵, 음량 분석값을 조합한 점수와 기승전결 탐색을 추가한다.
6. 렌더링 완료 뒤에만 클라이언트가 서버 작업 이력을 생성하고 현재 서버 API 계약의 편집 판단 데이터를 저장한다. 진행 중·실패·취소 작업은 서버 완료 이력으로 만들지 않는다.

## 기본 방향

* 기능을 작은 단위로 구현하고 실제 동작을 확인한다.
* 가능한 단순한 구조를 우선한다.
* 모듈 간 결합을 최소화한다.
* 각 모듈은 가능한 한 독립적으로 실행하고 테스트할 수 있도록 한다.
* 새로운 요구사항이 생길 때 필요한 설계와 문서를 추가한다.
